This file is a pointer. Do not read it as the setup steps.

Print the guide and follow each phase in order:

python3 scripts/setup_guide.py

When a phase is done, record it:

python3 scripts/setup_guide.py --complete <number>

Setup is not finished until this exits 0:

python3 scripts/setup_verify.py

The printed phases are the only setup steps. Claude Code plugin commands are in INSTALL.md (Claude Code section). install.ps1 runs the add and install commands.
