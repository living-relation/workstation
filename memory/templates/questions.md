## Questions to the user (decisions D-2026-11-25-question-ids, D-2026-11-28-rec-marker)
- Every question has an ID of exactly two characters: one capital letter and one digit 1-9 (A1 to A9, then B1 to B9, ...). Never longer, never a bare number, and never a number added to the ID (no "1. A1", no "A10").
- List questions by ID only, never as a numbered list.
- Each choice is one lower-case letter: a), b), c). No numbered choices.
- Mark the recommended choice with ⭐ right after its letter and before its words (`a) ⭐ <words>`), every time, and only that choice. No other marker ("(rec)", "Recommended", bold) replaces it.
- When only one choice really moves the work forward, take it, say so, and do not ask.
- Example: `- **A1 Default limits:** a) ⭐ each output's rating · b) leave 20 A`
