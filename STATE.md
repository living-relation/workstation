Cursor plugins do support hooks (`https://cursor.com/docs/reference/plugins`, `https://cursor.com/docs/hooks`). Their file shape is not Claude's, and a set `hooks` path replaces discovery of `hooks/hooks.json`, so `.cursor-plugin/plugin.json` points at `hooks/cursor-hooks.json` (`preToolUse`, `stop`, `${CURSOR_PLUGIN_ROOT}`). A live Cursor install was not run. The projects root is `WORKSTATION_PROJECTS_ROOT` when that path exists, else `C:\projects` when it exists, else `%USERPROFILE%\projects`. No root: the hooks allow and stay quiet. `WORKSTATION_PROJECTS_DENY_KEYWORDS` is optional and defaults to empty, so the old project word list does not ship. Deny and report text points at the root `AGENTS.md`.
